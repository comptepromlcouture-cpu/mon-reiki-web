# Déploiement web

L'application est publiée automatiquement depuis la branche `main` du dépôt web par GitHub Actions.

Adresse : `https://comptepromlcouture-cpu.github.io/mon-reiki-web/`

Le dépôt privé `mon-reiki-app` conserve la source de travail. Le miroir public `mon-reiki-web` sert uniquement l'application et relance le déploiement après chaque mise à jour de sa branche `main`. L'utilisateur ouvre uniquement l'adresse web normale dans Chrome ou Safari.

## Installation Android

1. Ouvrir l'adresse dans Chrome.
2. Menu ⋮ → « Installer l'application ».
3. Valider « Mon Reiki ».

## Installation iPhone

1. Ouvrir l'adresse dans Safari.
2. Partager → « Sur l'écran d'accueil ».
